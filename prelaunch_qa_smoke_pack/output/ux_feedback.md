# UX Feedback: Harbor Habit

Build reviewed: 0.8.3-beta
Release goal: Decide whether a small habit-tracking app is ready for a 100-person beta invite.

## Highest Leverage Feedback

- **P3 Reminder setup (high):** Retest Reminder setup with large-font settings and keep tap targets visible at mobile widths.
  - User impact: Accessibility issue for larger-text users
- **P5 Settings (high):** Make the result of the action obvious on Settings: confirmation, plain copy, or visible undo.
  - User impact: Trust gap before inviting real users
- **P6 Settings (high):** Make the result of the action obvious on Settings: confirmation, plain copy, or visible undo.
  - User impact: User cannot tell whether the change was saved
- **P7 Today screen (medium):** Make the result of the action obvious on Today screen: confirmation, plain copy, or visible undo.
  - User impact: Accidental taps are hard to recover from on a small phone
- **P8 First habit (medium):** Constrain long text on First habit so content wraps without covering counters or controls.
  - User impact: Visual polish issue that makes the app feel unfinished

## Product Note

The app has enough useful paths to keep testing, but the first beta invite should wait until account access, offline behavior, and visible confirmations feel dependable.
