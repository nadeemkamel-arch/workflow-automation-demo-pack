How A First Batch Works

1. Send A Few Items

Start with 3-5 rough items, whatever notes you already have, and photos if available.

2. Review A Sample

I return cleaned-up titles, descriptions, price ranges, and a small tracker so you can judge the fit.

3. Approve The Batch

If it helps, we agree on a small fixed batch before I do more. You approve every listing before posting.

What To Send First

For A Quick Sample

  • 3-5 item photos or rough notes
  • sale date or posting deadline
  • pickup-only or delivery expectation
  • anything broken, missing, or untested

Common First Batch

  • free 3-5 item sample
  • 8-10 item quick batch: about $25
  • 20-25 item tidy sale batch: about $45
  • printable sale sheet quoted after seeing the list

Owner Keeps Control

  • you approve every description
  • you post the final listings
  • you handle buyer messages and pickup
  • no sale guarantees or condition guesses
