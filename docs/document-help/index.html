The Annoying Word Problems

  • Styles drift everywhere. Headings, paragraphs, lists, and spacing no longer match.
  • Pages move unexpectedly. Section breaks, blank pages, headers, and numbering fight each other.
  • The manuscript looks unfinished. Chapter openings, margins, gutters, and running heads need a consistent system.
  • The PDF does not match Word. Fonts, images, page dimensions, or export settings produce a bad print file.

Clear Scope, Clean Handoff

Common Deliverables

  • clean editable Word file
  • consistent paragraph and heading styles
  • repaired sections, headers, footers, and page numbers
  • page size, margins, and gutter setup
  • print-ready PDF and page-by-page render check
  • short note explaining the changes

Only When Separately Agreed

  • copy editing or rewriting
  • cover design or spine layout
  • image restoration or complex full-bleed design
  • publishing-account access or uploads
  • ISBN, retailer, or distribution approval work
  • rush work before the file is inspected
