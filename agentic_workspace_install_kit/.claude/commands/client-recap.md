# /client-recap

Use this after an install, support session, workflow change, or weekly operator review.

## Inputs

- Session notes or completed checklist.
- Changes made locally.
- Decisions still pending.
- Any blocked tool or account access.

## Steps

1. Summarize the business outcome in plain English.
2. List what changed in the workspace.
3. Separate completed work from pending approvals.
4. Note any tool access the client must complete manually.
5. Provide the next three actions.

## Output

```markdown
## Client Recap

Today we set up:

- ...

What changed:

- ...

Still pending:

- ...

Next three actions:

1. ...
2. ...
3. ...

Ready to send/write: no
Approval needed: yes, client should review before this recap is shared externally.
Next human action: confirm the pending approvals or schedule the next support check.
```
